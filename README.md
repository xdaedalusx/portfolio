# Daniel Delgado, PhD — Portfolio

A collection of academic research, software, and design projects spanning augmented reality, human–computer interaction, UX research, and creative technology.

[**Portfolio Website**](https://xdaedalusx.github.io/portfolio/) · [**LinkedIn**](https://www.linkedin.com/in/danieldel1996/) · [**Email**](mailto:danieldelgado.xr@gmail.com)

## About

I’m a computer scientist and UX researcher based in San Francisco, California. I earned my PhD in Computer Science from the University of Florida in 2025. My work explores human–computer interaction, augmented reality, collaboration, and user-centered technology.

## Projects

### Galaxy Viz — Interactive Paper Citation Galaxy

An interactive 3D visualization of a research-paper network. Explore citation relationships, similarity links, clusters, and the structure of a scholarly landscape through a browser-based WebGL viewer.

**Technologies:** JavaScript, Three.js, WebGL, data visualization, network graphs

- [**Open the live Galaxy Viz website**](https://xdaedalusx.github.io/galaxy-viz/)
- [View Galaxy Viz source repository](https://github.com/xdaedalusx/galaxy-viz)
- [Read the Galaxy Viz UX case study](galaxy-case-study.html)

### Shared-Gaze Visualization in Augmented Reality
Developed and evaluated shared-gaze visualizations for collaborative AR tasks, investigating their effects on communication, social presence, and task performance.

**Technologies:** Unity, MRTK, C#, HoloLens 2, eye tracking

[View Project Folder](Projects/Shared-Gaze-Visualizations/)

### EMG-Based Human–Machine Interface in Virtual Reality
Developed a VR-based training environment exploring EMG-controlled prosthetic interaction and task performance.

**Technologies:** Unity, C#, VR, EMG, machine learning

[View Project Folder](Projects/EMG-Based-Human-Machine-Interface/)

### Augmented Reality Task Guidance
Explored multimodal AR guidance for complex tasks, combining user research and interactive prototypes to inform design recommendations.

**Technologies:** Unity, HoloLens 2, UX research, prototyping

[View Project Folder](Projects/Developing-User-Needs-for-Task-Guidance/)

### Multimodal Affect Detection
Investigated machine-learning methods for classifying affect from audio and visual data, including feature extraction and deep-learning approaches.

**Technologies:** Python, TensorFlow, deep learning

[View Project Folder](Projects/Machine-Learning-Affect-Detection/)

### iCarus — A Skinnable macOS Media Player
A SwiftUI media player inspired by the customizable interfaces of classic Windows Media Player, featuring custom skins, audio visualization, equalizer controls, and a media download workflow.

**Technologies:** Swift, SwiftUI, macOS

[View iCarus Repository](https://github.com/xdaedalusx/icarus)
- [Read the iCarus UX case study](icarus-case-study.html)

### Mandelbrot Explorer
An interactive fractal playground built with JavaScript and HTML Canvas. Zoom into the boundary, select regions, experiment with color maps, and export custom renders.

**Technologies:** JavaScript, HTML Canvas, generative art, mathematics

[Open the Mandelbrot Explorer](https://xdaedalusx.github.io/portfolio/mandelbrot.html)
