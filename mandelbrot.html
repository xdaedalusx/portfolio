01 / THE IDEA

One equation.
Infinite complexity.

The Mandelbrot set is formed by repeatedly applying z = z² + c, starting at zero. For each point on the complex plane, the renderer checks whether the sequence remains bounded or escapes toward infinity.

This browser version translates the core idea of my Python exploration into a canvas-based interactive experience. The rendering controls let you inspect the set at different scales, adjust iteration depth, and compare color mappings without leaving the page.
